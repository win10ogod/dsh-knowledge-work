# DSH 知識工作

為 DSH 0.2.0-rc.2 與 0.2.1-alpha.1 提供「知識工作」Agent 預設與持久工作流程。適用於研究整理、方案比較及知識維護，將問題、步驟、實際讀取的來源、論點、核查與報告放在同一個工作案中。

## 使用

安裝插件後，在新對話選擇「知識工作」Agent，再交付任務。例如：

- 研究一個問題，保存支持與反對結論的來源。
- 依相同條件比較方案，區分事實、推論與尚未確認之處。
- 恢復先前工作，重新讀取來源並更新受影響的論點。

左側「知識工作」頁面可查看工作案、進度、原文、比較結果及下載 Markdown 報告。此頁主要供檢視；在對話中要求 Agent 暫停、恢復或繼續工作。新預設使用 DSH 目前的模型與權限，保留原生檔案、Shell、技能、搜尋、規劃與委派工具，也能搭配已安裝的 agent-browser、Office 技能及 evidence-first-knowledge-work。

## 工作流程

1. 建立目標、範圍、工作模式及交付條件。
2. 將工作拆成具有依賴關係的步驟。
3. 用現有工具讀取來源，再保存該次真實工具結果或使用者提供文字。
4. 整理論點、引用、推論前提、未知及相反證據。方案比較以相同條件逐格連到論點。
5. 核查步驟完成情況、交付條件覆蓋、引用原文及來源更新。
6. 產生完整報告；若有缺口，交付明確標示限制的部分成果並暫停。

每次更動保留修訂紀錄；相同內容的重複更新不增加版本，也不使已完成的核查失效。來源文字不可原地覆寫；新增來源取代舊來源時，受影響的引用需要重新核查。模型不會因為只說「稍後繼續」就結束仍在進行的工作案：預設在同一回合接續；使用者停止、模型請求失敗、明確暫停或完成交付時停止續跑。既有工作案需要 `resume` 才會在新回合重新接手。

恢復上下文使用結構化進度與證據索引。原文與完整工作資料由工具按需讀取，不重播過去的助手行為軌跡。每次模型請求仍使用 DSH 已配置的模型、輸出上限及上下文管理。

## 工具

| 工具 | 用途 |
| --- | --- |
| `knowledge_task` | 建立、列出、讀取、恢復、暫停、取消工作案 |
| `knowledge_plan` | 定義步驟與依賴關係；修訂計畫使用版本檢查 |
| `knowledge_step` | 記錄一步的狀態、實際結果及證據關聯 |
| `knowledge_capture` | 擷取本會話真實工具結果或真人提供的文字 |
| `knowledge_claim` | 保存陳述、推論、未知、原文引用及分歧 |
| `knowledge_compare` | 用同一組条件比較各方案，保留未知資訊 |
| `knowledge_read` | 讀取工作案、原文、報告、修訂摘要與工具收據 |
| `knowledge_review` | 核查目前版本的交付條件與證據連結 |
| `knowledge_deliver` | 產生完整或部分 Markdown 報告 |

工具只存取目前工作區的工作案。新會話可透過 `knowledge_task list` 找回該工作區的既有工作。工具和模型可見的動態工作狀態只加入本插件的 Agent 預設。

## 證據範圍

`knowledge_capture` 保存 DSH 已提交的工具文字或真人訊息，不能直接填入臆造的來源正文，也不接受工作案自身輸出作為獨立證據。原始工具結果和 JSON 解碼後的文字可供引用；引用必須實際存在於保存內容中。工具在回傳前已截短的資料不會自動補齊，應再次讀取需要的片段。圖片、音訊等資料需先由可用工具轉成可核查的文字。

這些檢查能驗證來源收據、原文片段與流程完整性，不能自動證明來源正確或論證成立。Agent 仍需閱讀、比較適用範圍、解釋推論並處理相反證據。來源的發布日期與適用範圍是 Agent 標註；工具/訊息時間與擷取時間分別保存。部分成果不會標記為完整完成。

## 安裝與設定

使用 GitHub Release 的 `.tgz`：

```sh
dsh plugin --profile YOUR_PROFILE add ./dsh-knowledge-work-0.1.1.tgz
```

使用兩個原生插件條目：`knowledge-work` 提供儲存與工作台，`preset-knowledge-work` 註冊 Agent 預設。

```yaml
- id: knowledge-work
  config:
    autoContinue: true
    dataDir: ''
```

`autoContinue: false` 關閉工作案的同回合自動續跑，保留工具及資料。每次續跑都是模型請求，會產生相應用量。資料預設保存在 `$DSH_HOME/storages/knowledge-work/work.sqlite`；可用 `dataDir` 指定另一個目錄。停用插件保留資料。報告下載與工作台使用 DSH 原生連線認證。

## 開發

```sh
npm ci --ignore-scripts
npm run check
npm pack
```

測試涵蓋真實 Agent loop 搭配可控模型 adapter、原文擷取、引用核對、來源替換、工作恢復、部分交付、比較表、跨工作區隔離、停止與錯誤處理。實際模型與整包測試需另外使用隔離設定檔驗證。
